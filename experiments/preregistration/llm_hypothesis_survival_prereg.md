---

## 1. Research Question & Objective

This study evaluates whether trading hypotheses generated by the Substrate LLM (Ollama/Llama3 client) exhibit genuine predictive reasoning or represent pseudo-reasoning (hallucinated prompt overfitting).

> **Core Question**: Do LLM-generated hypotheses ($H_{\text{LLM}}$), produced by querying Ollama with domain grammar and feature glossaries, produce out-of-sample edge on surviving hypotheses that statistically exceeds randomly generated hypotheses ($H_{\text{Random}}$) from the exact same structural grammar?

---

## 2. Sample Size & Arm Definitions

1. **Treatment Arm ($H_{\text{LLM}}$, $N=150$)**:
   - 150 unique, grammatically valid hypotheses generated by calling `OllamaClient` with a strict JSON schema prompt containing the formal feature glossary and grammar bounds.
   - Parse-or-reject loop up to 400 total attempts.
   - Exact duplicate hypotheses within the arm are collapsed.
   - Hard stop condition: If `OllamaClient` errors or is unreachable, the run MUST abort. Generating hypotheses by any alternative fallback or template is strictly prohibited.
   - Frozen dataset saved to `data/hypotheses/llm_arm.json` along with complete raw generation log `data/hypotheses/llm_generation_log.json`.

2. **Control Arm ($H_{\text{Random}}$, $N=150$)**:
   - 150 unique, grammatically valid hypotheses generated by uniformly sampling features, operators, thresholds, and target modes from grammar $G$ using fixed seed `seed=42`.
   - Exact duplicate hypotheses within the arm are collapsed.
   - Frozen dataset saved to `data/hypotheses/random_arm.json`.

---

## 3. Data Split & In-Sample Survival Calibration

- **Data Window & Split**: 60% In-Sample (IS) / 40% Out-of-Sample (OOS) time-series split across committed daily datasets (`NIFTY`, `RELIANCE`, `TCS`).
- **In-Sample Binomial Survival Filter ($p < 0.10$)**:
  - A candidate hypothesis $H_i$ is calibrated as **IS-SURVIVED** if its in-sample directional hit rate or volatility expansion accuracy exceeds the empirical base rate with binomial test $p < 0.10$.
  - Calibrated threshold ensures the control random arm expects a non-zero number of in-sample survivors to prevent empty-set statistical artifacts.

---

## 4. Single Gate G-P3 & Statistical Significance Test

- **Target Metric**: Out-of-sample edge ($E_{\text{OOS}} = \text{OOS Hit Rate} - \text{Base Rate}$) computed strictly on the **IS-SURVIVING** subset of hypotheses for each arm.
- **Single Gate G-P3**:
  $$\text{Gate G-P3}: \text{Pooled One-Sided Mann-Whitney U Test } p < 0.05 \quad \text{on } E_{\text{OOS}}(H_{\text{LLM, survivors}}) \text{ vs. } E_{\text{OOS}}(H_{\text{Random, survivors}})$$

### Pre-Registered Verdict Matrix
